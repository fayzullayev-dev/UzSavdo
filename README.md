# UzSavdo (УзСавдо) — B2B Улгуржи Савдо Майдончаси 🇺🇿

> **UzSavdo** — Ўзбекистон Республикаси вилоятлари ва туманлари бўйича қишлоқ хўжалиги ва саноат маҳсулотларини сотиш ҳамда сотиб олишга мўлжалланган миллий B2B электрон савдо платформаси. Тизим Хокимият ва Савдо-саноат палатаси назорати остида хавфсиз битимлар тузиш, шартномаларни рақамли расмийлаштириш ва нархлар мониторингини таъминлайди.

## ✨ Асосий Имкониятлар ва Функциялар

### 1. Икки тилли тўлиқ локализация (Ўзбек / Русский)
* Платформа тўлиқ икки тилда (UZ / RU) ишлайди.
* Тилни ўзгартирганда нафақат интерфейс тугмалари, балки **барча 30 та маҳсулот эълонлари**, уларнинг тавсифлари, ўлчов бирликлари (`кг`, `т`, `шт.`, `мешок`), нархлари (`сум`) ва ҳудуд номлари автоматик равишда рус тилига мослашади.

### 2. Кенгайтирилган Эълонлар Каталоги ва Икки Босқичли Фильтр
* 14 та асосий тоифа бўйича саралаш (Қишлоқ хўжалиги, Қурилиш материаллари, Озиқ-овқат, Тўқимачилик, Кимё саноати ва ҳ.к.).
* СОАТО бўйича 14 та вилоят ва 200 дан ортиқ туманлар бўйича локация фильтри.
* Нарх оралиғи, янгилиги ва 4★ дан юқори рейтинг бўйича фильтрлаш.

### 3. Ҳокимият ва Давлат Буюртмачиси учун Бошқарув Панели (`/admin`)
* **1760px кенгликдаги профессионал таҳлилий бошқарув тизими:**
  * 8 та асосий кўрсаткич (KPI) карточкалари ва динамик спарклайн графиклари.
  * Ўзбекистоннинг интерактив SVG-харитаси (ҳудудлар фаоллиги даражаси бўйича).
  * Вилоятлар рейтинги ва савдо ҳажми ўсиш графиклари.
  * Ҳудудлараро товар оқими матрицаси («Қаердан → Қаерга»).
  * ТОП-10 Тадбиркорлар ва ТОП-10 Талабгир товарлар жадвали.
  * Кўп варақли расмий Excel (`.xlsx`) ҳисоботларини юклаб олиш ва A4 босма шакли (Печать).
  * Тадбиркорнинг батафсил карточкаси (ҳужжатлар, битимлар тарихи, блоклаш ва паролни тиклаш).

### 4. Шаффоф Рейтинг ва Баҳолаш Тизими (`/ratings`)
* Сотувчи ва харидорлар учун рейтинг тизими:
  * 5 та визуал юлдузчалар ва тезкор фикрлар чиплари билан шарҳ қолдириш.
  * Сотувчи томонидан мижоз фикрига бир марталик расмий жавоб бериш имконияти.
  * Вилоят бўйича энг кучли сотувчилар ТОП-рўйхати.

### 5. Хавфсиз Битимлар ва Электрон Шартномалар
* Харидор маҳсулотнинг исталган миқдорини чегирмасиз ва минимал чекловларсиз танлай олади.
* Электрон шартнома тузиш ва PDF нусхасини юклаб олиш.
* 72 соатлик буюртма назорати ва хавфсиз битим кафолати.

## 🛠 Технологик Стек

* **Фронтенд:** Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS, Recharts, Lucide Icons, Sonner Toasts.
* **Бэкенд:** NestJS 11, Node.js, REST API, Swagger/OpenAPI.
* **Маълумотлар базаси:** SQLite + Prisma ORM (Тайёр демл маълумотлар билан).
* **Монорепозиторий:** Turborepo, pnpm workspaces.

## 🚀 Маҳаллий Ишга Тушириш (Local Development)

```bash
# 1. Репозиторийни юклаб олиш
git clone https://github.com/fayzullayev-dev/UzSavdo.git
cd UzSavdo

# 2. Модулларни ўрнатиш
pnpm install

# 3. Prisma клиентни шакллантириш ва базани юклаш
cd apps/api
npx prisma generate
npx prisma db push

# 4. Лойиҳани ишга тушириш
# API бэкенд (порт 4000)
pnpm start

# Веб фронтенд (порт 3000)
cd ../web
pnpm dev
```
