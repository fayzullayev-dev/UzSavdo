## 🌟 Лойиҳа Ҳақида (Project Overview)

**UzSavdo** — Ўзбекистон ҳудудлари ўртасидаги улгуржи савдони рақамлаштириш, фермерлар, ишлаб чиқарувчилар, савдо корхоналари ва давлат харидорлари ўртасидаги тўғридан-тўғри алоқаларни мустаҳкамлаш мақсадида ишлаб чиқилган замонавий миллий B2B платформасидир.

Лойиҳа савдо жараёнларининг шаффофлигини, нархлар мониторингини ва битимларнинг қонуний ҳимоясини тўлиқ кафолатлайди.

## ✨ Асосий Имкониятлар ва Функционал

### 1. 🌐 Тўлиқ Икки Тиллилик (Ўзбек / Русский)
* Платформа тўлиқ икки тилда (UZ ва RU) бир зумда синхрон ишлайди.
* Тил алмаштирилганда нафақат бошқарув тугмалари, балки **барча маҳсулот эълонларининг номлари**, тавсифлари, ўлчов бирликлари (`кг`, `т`, `шт.`, `мешок`, `коробка`), нарх формати (`сум` / `soʻm`) ҳамда ҳудудлар (вилоят ва туманлар) автомат таржима қилинади.

### 2. 📦 Кенгайтирилган Эълонлар Каталоги ва Икки Босқичли Фильтр
* **14 та асосий тоифа:** Қишлоқ хўжалиги (сабзавот, мева, дон), Қурилиш материаллари, Озиқ-овқат, Тўқимачилик, Маиший кимё, Гўшт-сут маҳсулотлари ва бошқалар.
* **СОАТО миллий классификатори:** Ўзбекистоннинг барча 14 та ҳудуди ва 200 дан зиёд шаҳар ҳамда туманлари бўйича аниқ жойлашув бўйича саралаш.
* Нарх диапазони, янгилиги, талабгирлиги ва 4★ дан юқори рейтинг бўйича фильтрлаш.

### 3. 🏛️ Ҳокимият ва Давлат Мониторинги Бошқарув Панели (`/admin`)
* **1760px кенгликдаги давлат даражасидаги таҳлилий бошқарув тизими:**
  * **8 та асосий кўрсаткич (KPI):** Фойдаланувчилар, фаол эълонлар, тузилган шартномалар, якунланган савдо ҳажми (сўмда) ва спарклайн графиклари.
  * **Ўзбекистоннинг интерактив SVG-харитаси:** 14 та вилоят ва шаҳарлар бўйича савдо фаоллиги даражасини ранглар интенсивлиги билан акс эттириш.
  * **Ҳудудлараро товар оқимлари матрицаси («Қаердан → Қаерга»):** Қайси вилоят қайси ҳудудга қанча ҳажмда маҳсулот етказиб бераётганини аниқ ҳисоблаш.
  * **ТОП-10 Тадбиркорлар ва ТОП-10 Талабгир товарлар рейтинги.**
  * **Савдо битимлари воронкаси (Funnel analysis).**
  * **Кўп варақли расмий Excel (`.xlsx`) ва босма (A4) шаклида ҳисоботлар шакллантириш.**
  * **Тадбиркор карточкаси (Drawer):** Корхона СТИР маълумотлари, битимлар тарихи, блоклаш ва хавфсизликни бошқариш.

### 4. ⭐ Шаффоф Рейтинг ва Баҳолаш Тизими (`/ratings`)
* Сотувчилар учун ҳақиқий xаридорлар томонидан берилган 5 юлдузли баҳолаш тизими.
* Тезкор фикрлар чиплари (*"Сифатли маҳсулот"*, *"Нархи мос"*, *"Вақтида етказди"*).
* Сотувчи томонидан мижоз фикрига бир марталик расмий ва оммавий жавоб ёзиш имконияти.
* Ҳудудлар кесимида энг ишончли сотувчилар рўйхати.

### 5. 🤝 Хавфсиз Битимлар ва Электрон Шартномалар
* Харидор учун минимал буюртма чекловлари йўқ — исталган миқдорни эркин танлаш имконияти.
* Бир зумда электрон шартнома шакллантириш ва расмий PDF форматида юклаб олиш.
* 72 соатлик буюртма қабул қилиш назорати (қонуний кафолат).

## 🛠 Технологик Стек (Tech Stack)

| Йўналиш | Технология | Тавсифи |
| :--- | :--- | :--- |
| **Frontend** | `Next.js 15 (App Router)` | Замонавий SSR/SSG сервер архитектураси |
| **UI Library** | `React 19 + Tailwind CSS` | Тезкор, жавобгар ва тоза дизайн |
| **Analytics & Charts** | `Recharts + SVG Maps` | Интерактив графиклар ва миллий харита |
| **Backend API** | `NestJS 11` | Модулли, юқори унумли REST API сервери |
| **Database & ORM** | `Prisma ORM + SQLite` | Тўлиқ типланган ва реал маълумотлар билан таъминланган база |
| **Icons & Alerts** | `Lucide Icons + Sonner` | Нафис иконкалар ва анимацияли тост-хабарномалар |
| **Monorepo Tools** | `Turborepo + pnpm` | Юқори тезликдаги монорепозиторий бошқаруви |

## 📁 Демо Ҳисоблар ва Маълумотлар Базаси

Лойиҳа ичида қуйидаги тўлиқ реал маълумотлар тўплами олдиндан шакллантирилган:
* **30 та асл фотосуратларга эга улгуржи маҳсулот эълонлари;**
* **14 та вилоят ва 200 дан ортиқ туманлар (СОАТО маълумотномаси);**
* **14 та асосий иқтисодий товар тоифалари;**
* **Электрон шартномалар, буюртмалар ва мижозларнинг баҳолари тарихи.**

## 🚀 Маҳаллий Ишга Тушириш (Local Setup)

```bash
# 1. Репозиторийни клонирлаш
git clone https://github.com/fayzullayev-dev/UzSavdo.git
cd UzSavdo

# 2. Пакетларни ўрнатиш
pnpm install

# 3. Базани юклаш ва миграция қилиш
cd apps/api
npx prisma generate
npx prisma db push

# 4. Лойиҳани ишга тушириш
# API бэкенд (порт 4000)
pnpm start

# Веб фронтенд (порт 3000)
cd ../web
pnpm dev
```
