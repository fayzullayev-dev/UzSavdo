# Отчёт о разработке мобильного приложения UzSavdo (Android + iOS)

## 1. Стек и архитектура
- **Фреймворк**: Expo SDK 58 + React Native 0.88 + TypeScript (strict mode, 0 ошибок в `tsc --noEmit`).
- **Маршрутизация**: Expo Router (файловая навигация, нижняя панель вкладок Tabs, модальные экраны, стек).
- **Сетевой клиент**: TanStack Query + fetch API с поддержкой JWT Bearer-токенов и авто-роутингом.
- **Хранение сессий**: `expo-secure-store` для токенов доступа и refresh-токенов.
- **Интернационализация**: `@uzsavdo/i18n` с поддержкой мгновенного переключения узбекского (`uz` с корректными буквами `ʻ`, `ʼ`) и русского (`ru`) языков без перезагрузки.
- **Дизайн и UI**:
  - Токены цветов из спецификации ТЗ: `primary` (#1F5F4A), `primarySoft` (#E6F0EB), `accent` (#E07A3F), `background` (#F4F5F7), `surface` (#FFFFFF).
  - Скругления: карточки 20px, шапки 28px, кнопки 14px, чипы 9999px.
  - Кастомный компонент `TopToast` (выпадает сверху, исчезает через 2 секунды).
  - Кастомный `ConfirmSheet` и `FormSheet` (нижние выезжающие шторки).
  - **Полный запрет системных окон**: 0 вызовов `Alert.alert` и `Alert.prompt` во всём коде мобильного приложения.

## 2. Реализованные экраны и модули
1. **Вход и Регистрация (`/auth`)**:
   - Переключатель «Kirish» / «Roʻyxatdan oʻtish».
   - Двуязычный интерфейс UZ / RU с переключателем в шапке.
   - Поля для компании, ФИО, телефона, логина и пароля с глазом скрытия.
2. **Каркас приложения (`/(tabs)/_layout.tsx`)**:
   - 5 нижних разделов: «Bosh sahifa», «Eʼlonlar», центральная круглая приподнятая кнопка «Eʼlon joylash» (64px, +), «Buyurtmalar» и «Menyu».
   - Правое выдвижное меню (`RightMenuDrawer`) со всеми разделами (Savdo, Muloqot, Tarix, Boshqa), переключателем языков и кнопкой профиля/выхода.
3. **Главная страница (`/(tabs)/index.tsx`)**:
   - Верхний белый блок со сводкой и шевроном («Jami savdolarim ›»), крупная сумма с кнопкой скрытия («глаз»).
   - Горизонтальный ряд мини-карточек: Kutilmoqda, Faol eʼlonlar, Yakunlangan, Shartnomalar.
   - Капсула-подложка с 3 круглыми кнопками-переключателями (Savdolarim, Xaridlarim, Shartnomalarim).
   - Плашка бесплатного пробного периода (до 10.01.2027).
   - Сетка плиток 3×3 «Xizmatlar» с бейджем «yangi».
   - Горизонтальная прокрутка категорий и последних объявлений.
4. **Каталог объявлений (`/(tabs)/listings.tsx`)**:
   - Строка поиска, счётчик объявлений, 2-колоночная сетка `ListingCard`.
   - Шторка фильтра (`FormSheet`): выбор категорий, диапазон цен («dan» / «gacha»).
5. **Страница товара (`/listing/[id].tsx`)**:
   - Полноэкранная галерея, бейджи, плавающие кнопки назад/избранное.
   - Характеристики товара, регион, наличие.
   - Блок продавца (заблокирован до заключения договора по требованиям ТЗ).
   - Нижняя панель с кнопками регулировки количества (−/+) и кнопкой Accent «Sotib olish».
   - Оформление договора в бесплатный пробный период (0%) и получение контактов продавца.
6. **Размещение объявления (`/(tabs)/new-listing.tsx`)**:
   - 4-шаговый мастер (1 Mahsulot → 2 Narx va miqdor → 3 Rasmlar → 4 Qoʻshimcha).
   - Загрузка и компрессия фото через `expo-image-picker`.
7. **Заказы (`/(tabs)/orders.tsx`)**:
   - Вкладки «Kiruvchi» / «Mening buyurtmalarim».
   - Живой индикатор 72-часового регламентного таймера.
   - Кнопки «Qabul qilish» и «Rad etish».
8. **Договоры (`/contracts.tsx`)**:
   - Реестр номеров `№ UZ-2026-XXXX` со сторонами сделки и кнопками скачивания PDF.
9. **Профиль и Настройки (`/profile.tsx`)**:
   - Личные данные, логин, скрытый пароль (`••••••••`), переключатели Face ID / биометрии и push-уведомлений, выбор языка.
10. **История покупок и продаж (`/history/purchases`, `/history/sales`)**.
11. **Сообщения и чаты (`/messages.tsx`)**.
12. **Уведомления (`/notifications.tsx`)**.
13. **Рейтинги и отзывы (`/ratings.tsx`)** с оценками и официальными ответами.
14. **Помощь и FAQ (`/help.tsx`)**.
